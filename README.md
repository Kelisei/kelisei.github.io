# Kelisei Ventura - Blog & Portfolio

Personal website, portfolio, and technical blog built with Astro and Tailwind CSS styled in the Catppuccin Mocha colorscheme.

## Writing Blog Posts

Add Markdown (.md) files to src/content/blog/ with frontmatter:

```yaml
---
title: "Post Title"
description: "Brief summary"
pubDate: 2026-09-23
---
```

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
